# Plant Parent

Tick the houseplants you own from 24 common varieties (real watering intervals,
light needs, pet-toxicity flags), set last-watered dates, and get a 14-day
watering schedule with overdue callouts. One-tap "just watered" resets a plant's
clock. Pet-safe and low-light filters. All state in localStorage with real
date arithmetic - the schedule keeps ticking when you come back tomorrow.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/plant-parent/

Pure client-side HTML/CSS/JS.
